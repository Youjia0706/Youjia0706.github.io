Hyperledger test-network 檔案說明

發表於2025-06-26|區塊鏈
|瀏覽量:

  • addOrg3：

    • addOrg3.sh：添加 Org3 的主腳本。
    • ccp-generate.sh、ccp-template.json、ccp-template.yaml：用於生成 Org3 的連接配置文件 (Connection Profile)。
    • compose (及其 docker 和 podman 子目錄)：包含添加 Org3 後，需要啟動其 Peer 和 CA 的 Docker Compose / Podman Compose 檔案 (compose-org3.yaml, compose-ca-org3.yaml 等)。peercfg/core.yaml 則是用於配置 Org3 Peer 的核心設定。
    • configtx.yaml：用於將 Org3 添加到通道配置的 configtx.yaml 片段。
    • fabric-ca/org3：Org3 的 Fabric CA 伺服器配置。
    • fabric-ca/registerEnroll.sh：註冊和登記 Org3 身份的腳本。
    • org3-crypto.yaml：用於 cryptogen 或其他憑證生成工具的配置。

  • bft-config：

    • configtx.yaml：用於 BFT 排序服務的 configtxgen 配置。

  • compose (及其 docker 和 podman 子目錄)：

    • compose-bft-test-net.yaml：如果選擇 BFT 模式，network.sh 會使用的 Docker Compose 檔案。
    • compose-ca.yaml：啟動 CA 容器的 Compose 檔案。
    • compose-couch.yaml：啟動 CouchDB 狀態資料庫的 Compose 檔案。
    • compose-test-net.yaml：預設的 Raft 模式下的主要 Compose 檔案。
    • peercfg/core.yaml：這是主要網路 Peer 的核心配置檔。

  • configtx：

    • configtx.yaml：預設的 Raft 模式下的 configtxgen 配置。

  • organizations：這是生成所有加密檔案的資料夾。

    • ccp-generate.sh、ccp-template.json、ccp-template.yaml：生成初始 organization 的連接配置文件。
    • cfssl：這個子目錄表明 test-network 也可以使用 cfssl 工具來生成憑證，提供了更細粒度的控制。它包含各種 CSR (Certificate Signing Request) 範本和 registerEnroll.sh。
    • cryptogen：這個子目錄包含了 crypto-config-orderer.yaml、crypto-config-org1.yaml、crypto-config-org2.yaml。這些是 cryptogen 工具的配置文件，定義了每個組織的節點、使用者和 MSP 結構，用於自動生成所有憑證和金鑰。
    • fabric-ca：包含 OrdererOrg、Org1、Org2 的 Fabric CA 伺服器配置 (fabric-ca-server-config.yaml) 和 registerEnroll.sh 腳本，用於通過 Fabric CA 服務器來註冊和登記身份。

  • prometheus-grafana：

    • docker-compose.yaml：啟動 Prometheus 和 Grafana 容器的 Compose 檔案。
    • grafana 和 prometheus 子目錄：分別包含 Grafana 的儀表板配置、資料源配置和 Prometheus 的監控目標配置。

  • scripts：

    • add_new_orderer_to_config.py：Python 腳本，用於動態添加新的 Orderer 節點到通道配置中。
    • ccutils.sh： chaincode 工具腳本。
    • configUpdate.sh：用於提交通道配置更新的腳本。
    • createChannel.sh：創建通道的腳本。
    • deployCCAAS.sh：部署 chaincode 即服務 (CaaS) 的腳本。
    • deployCC.sh：部署普通 chaincode 的腳本。
    • envVar.sh：環境變數設定腳本。
    • orderer.sh, orderer2.sh, orderer3.sh, orderer4.sh：用於設置特定 Orderer 節點的環境，以便執行命令。
    • org3-scripts：專門為 Org3 準備的腳本，用於加入通道和更新通道配置。
    • packageCC.sh 和 pkgcc.sh：用於打包 chaincode 。
    • setAnchorPeer.sh：設置 Anchor Peer 的腳本。
    • utils.sh：通用工具腳本。
