uv & pip 指令對照表

功能 pip 指令 uv 指令
建立虛擬環境 python -m venv .venv uv venv
安裝套件 pip install pandas uv pip install pandas
一次安裝 requirements.txt pip install -r requirements.txt uv pip install -r requirements.txt
更新套件 pip install --upgrade pandas uv pip install --upgrade pandas
移除套件 pip uninstall pandas uv pip uninstall pandas
查看已安裝套件 pip list uv pip list
查看套件版本 pip show pandas uv pip show pandas
匯出套件清單 pip freeze > requirements.txt uv pip freeze > requirements.txt
清除快取 pip cache purge uv cache clean
