Git 常用指令

發表於2024-05-13|工具
|瀏覽量:

一、初始化與設定

功能 指令
初始化 git 專案（在專案資料夾內執行） git init
設定使用者名稱 git config --global user.name "你的名字"
設定使用者 Email git config --global user.email "你的Email"
查看設定 git config --list

二、基本操作

功能 指令
查看檔案狀態 git status
將檔案加入追蹤 git add 檔名
將全部修改加入追蹤 git add .
建立一次提交（commit） git commit -m "訊息"
查看提交歷史 git log
簡短查看提交歷史 git log --oneline

三、分支操作

功能 指令
查看分支 git branch
建立新分支 git branch 分支名
切換分支 git checkout 分支名
建立並切換分支 git checkout -b 分支名
合併分支 git merge 分支名
刪除分支 git branch -d 分支名

四、遠端操作（GitHub）

功能 指令
新增遠端倉庫 git remote add origin https://github.com/帳號/倉庫.git
查看遠端 git remote -v
推送到 GitHub (第一次) git push -u origin main
之後推送修改 git push
從遠端抓取更新 git pull
複製（clone）遠端專案 git clone https://github.com/帳號/倉庫.git

五、常用技巧

功能 指令
取消暫存檔案 git reset 檔名
回到上一次提交（保留修改） git reset --soft HEAD~1
回到上一次提交（丟掉修改） git reset --hard HEAD~1
比較修改差異 git diff
查看某次 commit 詳細內容 git show commitID
