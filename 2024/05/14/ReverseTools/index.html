靜態分析工具

IDA 快捷鍵

IDA:https://hex-rays.com/ida-free/

  • 快捷鍵
    • Space: 在 Text View / Graph View 切換
    • Tab:在視窗之間切換
    • Esc:回到上一個步驟
    • Ctrl + Enter：回到下一個步驟
    • Ctrl + e: 程式的 Entry point
    • ; : 註解
    • x:顯示呼叫此函式的位置（reference）
    • n:變更名稱
    • y:變更型別
    • h:變更表示方式(dec/hex)
    • u:取消定義
    • a:當成字串
    • g:跳到要分析的位址
    • c:轉成 code
    • Alt + m: 把該位置加入書籤
    • Ctrl + m: 瀏覽書籤
    • Shift+F12：顯示這支程式所出現的文字

官方文件:https://hex-rays.com/products/ida/support/ida_cheatsheet.pdf

動態分析工具

GDB 指令

  • 常用語法
    • gdb -tui test.exe:開啟簡易 GUI 介面
    • layout asm: 在 GDB 中顯示一個窗口，其中顯示正在 debug 的程式的 assembly code
    • set disassembly-flavor intel:將格式從 AT&T 變為 intel
    • b(break):設定中斷點
      b main
      b *address
    • r(run):執行程式
    • c:繼續執行
    • info:查看 display, breakpoint 等等的設定狀態
      • info file:來觀察這個程式的進入點跟各區段位置
      • info function:顯示目前程式中已定義的所有函數及其相關資訊。
    • si:步入指令
    • ni:步過指令
    • x:顯示記憶體內容(x/3i 0x401000:從 0x401000 開始顯示 3 個指令)
    • vmmap:查看 address space
    • disas(disassemble): 反編譯
      • disas main:反編譯 main 程式碼

x64dbg

  • 快捷鍵
    • F7:單步執行(Step into)
    • F8:單步執行(Step over)
    • F9:執行
    • F2:下中斷點
    • Ctrl+F2:重新執行
    • Ctrl+G:跳到指定的 address
    • Enter:進到某個 function
    • +/-:回到上/下一個位置
    • ; :註解
    • alt+G:轉成 Graph

Windbg

Basic command

  • | - Process status
    • 查看⽬前 debug 的 process 資訊
  • ~ - Thread status
    • 類似 gdb 中 thread info 可以看 thread 資訊
    • ~[num]s 切換 thread

Display Memory

  • d{b|d|q|u} [ memory address ]
    • 可查看 address 的 memory 內容
    • b/d/q/u 分別是讀取 byte/dword/qword/unicode
    • 可加上 Ln 表⽰要列出 n 項

Display Type

  • dt [module!]Name [address]
    • 顯⽰ Type 結構，加上 address 可以該 type 形式顯⽰該 address 的內容
    • Module 表⽰為在哪個 module 底下的 type
    • 也可以加在 -rn ，可以讓在 struct 中的 struct 也顯⽰出來 n 表⽰顯⽰ n 層，r 為 recursive

Enter Value

  • e{b|d|q} address [Value]
  • e{a|u|za|zu} address “String”
    • 對某塊記憶體位置寫值或字串
    • u : unicode string
    • za : NULL-terminated ASCII string
